## 第三版（当前版本）

> 更新时间：2026-08-17

- 新增“转专业与专业分流”章节，整理转专业基本条件、申请类别、志愿录取、同分排序、专业分流规则和隐私处理提醒。
- 新增“保研考研与就业”章节，概括推免类型、保研准备、考研理解、就业准备和信息渠道。
- 新增“奖学金综测与竞赛”章节，梳理综合奖学金、综测计算、国家奖学金、助学金、竞赛认定和材料保存建议。
- 新增“校园建筑与办事地点”章节，按南校区、北校区和常用办事地点整理新生第一周常用空间。
- 新增“入学前准备清单”章节，整理必带材料、行李邮寄、床品洗护、军训用品、常用药品和安全提醒。
- 将新增章节接入首页快速入口、侧边栏导航、README、SUMMARY 和全书阅读版，确保网页阅读、站内搜索和 PDF 导出都能覆盖新内容。

## 第二版

> 更新时间：2026-08-15

- 修正了与宿舍相关的错误内容和容易产生误解的表述，尽量区分校内宿舍、鹏远公寓及不同楼栋之间的差异。
- 加入了更明显的页面动态效果与交互体验，包括首页视觉优化、页面动效、主题细节调整等。
- 优化校园地图展示，替换为学校官网高清地图，并支持点击放大、鼠标滚轮缩放、拖动平移和缩放比例显示。
- 补充并优化网站访问方式，除 GitHub Pages 外，也部署到 Cloudflare Pages，方便同学们多一个访问入口。
- 增加免责声明、联系方式、贡献入口和部分站点说明，便于后续持续维护。
