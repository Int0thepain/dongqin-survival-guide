学校设有四个食堂。

| 食堂 | 营业时间 | 收费方式 |
| --- | --- | --- |
| 一号餐厅 | 自助档口 10:30-13:20、17:00-19:20；其他档口 6:30-21:00 | 校园卡 |
| 民族餐厅 | 6:50-13:20、16:00-19:00 | 校园卡 |
| 校六食堂 | 提供早午晚餐，建筑面积 1800 m² | 校园卡 |
| 鹏远餐厅 | 正常供餐 | 支付宝/微信 |

注：菜品丰富、价格亲民，无论口味偏好如何都能找到适合自己的选择。校六食堂和一号餐厅口碑较好。
