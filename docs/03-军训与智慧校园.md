## 军训安排

报到后约 3 天左右开始军训，军训时长约 3 周。下雨天和周日可休息，平时训练强度适中，晚上一般由各系组织学唱校歌，军训结束后有比赛。

建议提前准备：

- 防晒用品
- 舒适鞋垫
- 大容量水杯

## 校园一卡通

<span class="mark-green">校园一卡通是东秦重要的生活工具</span>，可用于：

- 进出校门和宿舍
- 食堂就餐
- 超市消费
- 开水房打水
- 浴室洗浴
- 图书借阅
- 机房上机
- 体能测试认证

## 校园卡充值方式

1. “东秦校园卡”小程序 / “智慧东秦”APP / “智慧东秦”公众号，点击“充值”。
2. 支付宝搜索“校园派”，选择“东北大学秦皇岛”，按提示充值。

## 校园网

- 可使用移动、联通、电信、广电的校园宽带。
- 每个账号可绑定两台设备。
- <span class="mark-blue">校园网每月免费 5G 流量，超出部分每 G 收费 1 元。</span>
- 推荐办理运营商套餐，约 49 元/月，宽带不限速。

## 一网通办

- 入口：https://eone.neuq.edu.cn
- 账号：学号
- 初始密码：身份证后六位
