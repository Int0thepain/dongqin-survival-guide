# 项目说明与更新规则

## 来源

本文档由《东北大学(秦皇岛)2026届新生入学生活指南.pdf》转换整理而来。整理目标是便于后续持续更新、分类检索和网页发布。

## 信息有效性

原指南提示：本指南依据学校现行政策及往年经验整理，仅供参考。具体安排请以录取通知书及学校最新官方通知为准。更多信息请关注东北大学(秦皇岛)官网和招生网。

- 官网：https://www.neuq.edu.cn
- 招生网：https://zs.neuq.edu.cn

## 推荐维护方式

- 正文使用 Markdown 文件维护。
- 每个页面开头或结尾可补充“最后更新时间”。
- 对时间、金额、地点、电话号码、系统网址等信息建立校对清单。
- 班级内部版可以先收集真实问题，公开版再提炼成通用内容。

## 投稿建议

投稿内容建议包含：

- 具体问题或场景。
- 可验证的信息来源。
- 适用对象，例如新生、某学院、鹏远公寓、校内宿舍等。
- 信息是否可能过期。
