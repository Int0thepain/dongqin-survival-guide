## 学费标准

2026 年学费标准如下。

| 专业类别 | 学费/年 |
| --- | --- |
| 经济学类、工商管理类、机械类、自动化类、仪器类、外国语言文学类、数学类、材料类等 | 6240 元 |
| 信息管理与信息系统、电子商务、计算机科学与技术、物联网工程、电子信息工程、通信工程等 | 6240 元 |
| 民族学 | 5760 元 |
| 计算机科学与技术（中外合作办学）、通信工程（中外合作办学）、应用统计学（中外合作办学） | 56000 元 |
| 数学与应用数学（中外合作办学） | 50000 元 |

注：按大类招生的，专业分流后按实际专业标准缴费。除中外合作办学专业外，其他专业每学年末根据实际修读学分结算，多退少补。

## 缴费方式

- WEB 端：<span class="mark-blue">https://pay.neuq.edu.cn</span>
- 公众号：关注“东北大学秦皇岛财经处”，点击“缴费平台”
- 缴费时间：2026 年 8 月 25 日起

## 体检费

体检费：60 元/年·生。

## 助学贷款提示

办理了生源地或校园地助学贷款的新生，<span class="mark-red">不要登录缴费平台缴纳学宿费，以免重复收款。</span>
