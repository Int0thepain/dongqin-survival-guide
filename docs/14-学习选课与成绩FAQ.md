## 公共课与专业课

**公共课**是多数专业都会学习的课程，例如思政类、英语、体育、高等数学、线性代数等。  
**专业课**是根据专业方向设置的课程，例如计算机类大一可能接触 C++、计算机导论，后续学习 Java、数据结构等。

培养方案可参考教务处相关页面：

- 计算机与通信工程学院培养方案：http://jwc.neuq.edu.cn/rcpy/pyfa/jsjytxgcxy.htm

## 哪些课需要自己选

补充材料中提到：

- 专业课和大类平台课通常由教务处统一安排。
- 部分公共基础课需要自行选择任课教师或教学班，例如高等数学、线性代数、体育。
- <span class="mark-blue">选课时建议使用校园网，浏览器可优先尝试 Chrome 或 Firefox。</span>

<span class="mark-red">实际选课规则以当学期教务通知为准。</span>

## 成绩类型

常见成绩类型包括：

- **百分制**：常见于考试课，通常由平时成绩、作业、实验、期中/期末考试等组成。
- **五级制**：优秀、良好、中等、及格、不及格。
- **两级制**：合格、不合格。

具体课程如何给分，应看任课老师的课程说明。

## 大一上计算机类课程参考

补充材料中记录的计算机类大一上课程经验包括：

- 思想道德修养与法律基础：考查课，常见考核为考勤 + 期末报告。
- 形势与政策：考查课，常见考核为考勤 + 期末报告。
- 心理健康教育：考查课，常见考核为考勤 + 期末报告。
- 职业生涯与发展规划：考查课，可能由辅导员老师授课。
- 军事训练：考查课。
- 高等数学：考试课，可能分 A/B 班。
- 线性代数：考试课。
- 计算机导论：常见考核为考勤 + 期末考试。
- C++ 程序设计：常见考核为考勤、作业、实验、期末考试等。
- C++ 课程设计：偏实践和答辩，重视动手能力。

材料中提醒：大一年级上学期一般需注意最低修读学分要求，<span class="mark-red">否则可能触发学业警示</span>。具体阈值请以当年培养方案和学院通知为准。

## 选修课

选修课可用于拓展兴趣和补充学分。需要注意：

- 大学四年至少需要修满一定选修学分，具体看培养方案。
- 艺术类选修课通常有最低学分要求。
- 线上选修课一般在学习通等平台完成。
- 线下选修课可能集中在周末上课。
- <span class="mark-red">文化素质类选修课挂科后可能没有补考，后续可能需要重选覆盖</span>，具体以教务规则为准。
- 大一可选课程可能较少，热门课难抢，注意通知和开放时间。

补充 FAQ 中还提到，选修课种类较多，开课前通常会有选课文件，也可以在教务系统或本学院培养方案中查看。不要只凭往届截图判断当年课程，<span class="mark-blue">以系统中实际开放的课程为准</span>。

## 绩点怎么理解

补充材料记录中强调：<span class="mark-purple">绩点可以理解为学习成绩的函数，和专业分流、推免、奖学金、毕业资格等事项相关。</span>

常见理解方式：

- 百分制成绩通常按规则折算为绩点。
- 60 分以下通常绩点为 0。
- 五级制、两级制有对应折算规则。
- 平均学分绩点会综合课程绩点和学分。

具体公式和折算规则应以最新版学生手册、教务处文件为准。

## 学分、绩点、综测的区别

- **学分**：课程通过后获得，是毕业资格的重要条件。
- **绩点**：学习成绩的量化结果，和排名、分流、推免等关系密切。
- **综测**：综合素质测评，通常由学习成绩、竞赛、学生工作、文体活动、志愿服务等共同构成。

补充材料中的经验提醒很有价值：<span class="mark-purple">不要把“参加活动”简单等同于“有用”。如果活动只带来少量综测分，但占用大量时间，应衡量投入产出。</span>

## 缓考、补考与重修

补充材料中整理的常见经验：

- 考试期间原则上不随意请假。
- 因病或不可抗力申请缓考，一般需要提前向学院教学办公室申请并经审批。
- 缓考和不及格课程可能在下学期开学初参加补考，部分课程或环节不安排补考。
- 重修需要重新参加课程学习。
- 旷考、违纪、取消考核资格等情况会有更严格处理。

这些规则影响很大，<span class="mark-red">具体办理务必问辅导员、教学办或查看最新版教务文件。</span>

## 科创竞赛与实验室

适合关注的方向包括：

- ACM 程序设计竞赛
- “挑战杯”
- 数学建模
- 电子设计竞赛
- 学院/学校创新创业项目
- 实验室招新

大学生创新创业中心官网：http://cxcyzx.neuq.edu.cn/index.htm

实验室适合希望在课余时间提升实践能力、科研能力、项目经验的同学。加入方式可能包括统一招新、老师课上介绍、主动邮件联系等。

补充经验中对“实验室”有两类理解：

- 一类是老师或课题组带着做项目、论文或横纵向课题，更偏科研和工程实践。
- 一类是学生竞赛团队，例如智能车、Robomaster、Robocon、ACM 等，更偏训练、比赛和项目协作。

大一能否进入实验室或竞赛队，可能看绩点、面试表现、基础能力和招新名额。<span class="mark-green">想参加可以多关注招新通知，提前准备，但不用因为一次没进就否定自己。</span>

## 转专业与双学位

补充 FAQ 中对转专业的经验提醒比较集中：

- 转专业政策每届可能不同，26 届应等待学校正式文件。
- 常见影响因素可能包括绩点排名、高数、大学英语等课程成绩。
- 转专业后可能需要补修原专业没有学过的课程，短期内会增加学习压力。
- <span class="mark-red">转专业难度、名额和条件应以当年学校文件为准</span>，不要只按往届经验做决定。

关于双学位，补充材料中仅提到经验上“不太确定/貌似没有”，这一点不适合写成结论。建议有需求的同学直接查询教务处培养方案、辅修/双学位通知，或咨询学院教学办。

## 英语分班、四六级与雅思

- 大一是否能报名四级，通常要看当年学校和学院安排。补充材料中提到有年份大一即可报名，且可能在军训期间关注报名。
- 开学英语分班主要用于分层教学，不等同于四六级考试结果。
- 大学英语免修、雅思成绩折算等规则如有，应以当年文件和课程要求为准。
- 期末考试、分层教学质量和任课教师安排可能跨学院流动，不建议简单理解成“A 班一定更好”或“B 班一定更差”。

## 专业学习与电脑准备

是否提前预习大一课程，取决于个人目标。补充经验中普遍认为不必过度焦虑，想冲高绩点可以开学后认真跟课；想进实验室或竞赛队，可以提前补一点编程、数学或专业基础。

关于电脑：

- 工科、计算机、自动化等专业通常建议准备一台稳定的笔记本。
- 没有明确偏好时，Windows 兼容性更稳；Mac 是否合适要看专业软件、预算和个人习惯。
- 材料、数学等专业是否需要高性能电脑差异较大，建议问本专业学长学姐或查看课程软件要求。
- <span class="mark-green">不要只按“游戏本/轻薄本”标签判断，重点看课程软件、续航、重量、售后和预算。</span>

## 学生组织、社团、实验室怎么选

补充材料中对三类组织的区分比较清楚：

- **社团**：兴趣导向，更适合发展爱好、认识同伴。
- **学生会/部门**：偏学生工作和服务，可能涉及活动组织、协调沟通和综测。
- **实验室/竞赛队**：偏专业能力和项目经验，需要投入较多课余时间。

选择建议：

- 大一可以适度尝试，但不要一口气报太多。
- 想提高专业能力，实验室和竞赛队更直接。
- 想锻炼组织协调，学生组织更合适。
- 想保持兴趣和社交，社团更轻松。
- <span class="mark-purple">任何组织都要考虑时间成本，学习优先级不能丢。</span>

关于班委，补充 FAQ 中提到：班长、团支书、学习委员等岗位事务相对更多，其他岗位压力可能较小。班委经历可能对综测、评优、入党积极分子培养等有帮助，但对学业保研、科研保研等路径不应夸大。是否竞选，建议根据精力、沟通意愿和对班级事务的兴趣决定。

## 奖学金

补充材料中提到的奖学金类别包括：

- 本科生单项奖学金
- 本科生综合奖学金
- 校长特别奖学金
- 捐赠类奖学金
- 创新创业奖学金
- 国家奖学金
- 国家励志奖学金
- 无偿献血爱心奖学金

校综合奖学金可能按“学业成绩 + 综合素质测评”综合排名，具体比例、评奖比例和条件每年可能调整，<span class="mark-red">应以当年学院/学校文件为准。</span>

体育课本身有学分，体育课成绩可能影响学业成绩或绩点计算。补充材料中未提到奖学金有单独体育成绩门槛，但具体奖学金条件仍应以当年评奖文件为准。

## 推免保研

补充 FAQ 中提到，保研通常主要看绩点，竞赛、论文、专利软著等可能按规则参与加分或评价。不同学院、不同类型推免路径差异很大。

需要注意：

- 学业推免和综测不是一回事，班委、学生工作更可能影响综测、评优或入党相关事项。
- 竞赛能否加分、加多少分、最多取几项，通常会有学校或学院星级表、加分细则。
- 支教保研、辅导员保研、科研保研等路径的名额、条件和竞争范围不同。
- <span class="mark-red">推免政策每年都可能调整，不能只凭往届口述做规划。</span>

## 考证相关

- 英语四级通过后方可报考六级，常见合格线为 425 分。
- 四六级可多次刷分，部分企业或升学场景会参考。
- 计算机等级证书是否需要考，取决于专业、个人规划和精力。补充材料建议可以考虑计算机二级，但计算机类同学也应根据实际情况判断。

## 学习地点建议

补充材料中的经验很朴素但实用：<span class="mark-green">大学学习主要靠自学，宿舍不一定适合长期学习。</span>想提高效率，可以多去：

- 工学馆
- 图书馆
- 其他自习室

图书馆开放时间可能随学期调整，建议以图书馆最新通知为准。
