# 东北大学秦皇岛分校计算机与通信工程学院基础课程简介

> 根据所提供的电子信息工程、通信工程、物联网工程、计算机科学与技术专业课程表整理。重复课程已合并，共 18 门；具体教学安排以当届培养方案和课程教学大纲为准。(由于不同专业学分要求不同,这里只附上课程介绍,具体学分内容参见计算机与通信工程学院官网详细培养方案)

## 1. 计算机引论

课程帮助学生建立对计算机学科的整体认识。主要介绍计算机的发展与应用、信息的表示方法、软硬件系统的基本组成，以及操作系统、网络、程序设计、数据、人工智能和网络安全等概念。课程也会涉及专业学习路径、工程规范和职业伦理。学习后，学生应能理解计算机系统各部分的作用和联系，掌握基本术语，并为后续编程与专业课程建立清晰的知识框架。

## 2. C++程序设计

课程以 C++ 为工具训练程序设计思维。内容包括数据类型、控制结构、函数、数组、指针等基础语法，以及类与对象、封装、继承、多态、模板、异常处理和标准库容器。学生通过上机练习学习把实际问题拆解为算法和模块，并完成编写、调试与测试。课程强调代码规范和问题求解能力，是数据结构、算法设计及软件开发类课程的重要基础。

## 3. 电路原理

课程研究电压、电流和功率在集总参数电路中的基本规律。主要学习元件模型、欧姆定律、基尔霍夫定律、电阻电路等效变换、节点和回路分析、网络定理，以及正弦稳态、暂态过程和频率响应。学生通过计算、仿真或实验建立电路模型并分析工作状态，理解分析结果与工程现象的对应关系，为电子技术、通信和硬件系统课程提供必要的理论基础。

## 4. 模拟电子技术基础

课程学习连续时间模拟信号的产生、放大、处理与转换。内容通常包括半导体二极管、三极管和场效应管，基本放大电路、集成运算放大器、反馈、振荡、功率放大及稳压电路等。学生需要从器件特性出发分析静态工作点、增益、频率响应和失真，并结合实验掌握测量与排故方法。该课程是理解传感接口、通信前端和模拟电子系统的基础。

## 5. 数字电子技术基础

课程研究用二进制逻辑表示和处理信息的电子电路。主要内容包括数制与编码、布尔代数、逻辑门、组合逻辑电路、触发器、寄存器、计数器、时序逻辑电路及模数/数模转换。学生将学习化简逻辑表达式、阅读时序图，并完成简单数字电路的设计、仿真和实验验证。课程把抽象的逻辑规则与硬件实现连接起来，是计算机组成、嵌入式系统和数字通信的重要基础。

## 6. 物联网导论

课程从“感知—传输—平台—应用”的角度介绍物联网系统。内容一般涉及传感器与 RFID、无线通信、嵌入式设备、云平台、边缘计算、数据处理以及安全隐私等概念，并结合智慧城市、工业互联网和智能家居等案例说明系统构成。重点是建立系统视角，理解应用需求、设备能力、网络连接和数据服务之间的关系，为后续学习物联网软硬件开发和系统集成奠定基础。

## 7. 离散数学

离散数学是计算机科学的重要数学工具，研究可数、离散对象及其关系。课程通常包括命题与谓词逻辑、集合、关系与函数、组合计数、图论、代数结构和递推等内容。学生通过证明、建模和计算，学会严谨描述算法、数据结构和网络问题，培养抽象、归纳和演绎能力。它为算法分析、数据库、编译原理、密码学和人工智能等课程提供理论基础。

## 8. Java程序设计

课程以 Java 语言为载体学习面向对象程序设计和基本应用开发。主要内容包括基本语法、类与对象、接口和继承、异常处理、集合框架、文件与流、多线程及常用开发工具。教学通常通过小型项目训练学生完成数据处理、界面或网络功能，并重视代码规范、调试测试和模块协作。学习后，学生应能组织较完整的 Java 程序，理解面向对象设计的基本思想。

## 9. 复变函数与积分变换

课程在高等数学基础上研究复变量函数与常用积分变换。内容包括复数和解析函数、复积分、级数展开、留数计算，以及傅里叶变换和拉普拉斯变换等。学生学习利用变换把微分方程、信号和系统问题转化到更便于处理的域中，再求解和还原。课程训练从函数性质和变换观点分析工程问题的能力，是信号与系统、通信原理和控制类课程的数学基础。

## 10. 数据结构

课程研究数据的组织方式以及相应操作的效率。内容通常包括线性表、栈、队列、串、树、图和散列表等逻辑结构，顺序存储与链式存储等实现方式，以及查找、排序、遍历等基本算法。学生还会分析时间复杂度和空间复杂度，学习根据问题特点选择合适的数据结构，设计正确、清晰且可维护的程序。它直接支撑算法、数据库、操作系统和软件工程等后续学习。

## 11. 信号与系统分析

课程建立分析连续和离散信号、线性时不变系统的基本方法。内容包括信号表示与分类、系统性质、卷积、微分方程模型、傅里叶级数与变换、拉普拉斯变换、Z 变换和频域响应等。学生从时域与变换域两种视角理解系统对输入信号的作用，并求解滤波、调制和传输中的基本问题。该课程是通信、数字信号处理、控制和图像处理方向的理论基础。

## 12. 数字通信原理

课程讲解数字信息如何在有噪声的信道中可靠、高效地传输。主要内容包括数字基带传输、信号空间、脉冲编码调制、数字调制与解调、同步、信道编码、误码率和带宽效率等，并讨论噪声、衰落和干扰的影响。学生将理解从比特到波形再到接收判决的完整通信链路，能够用基本指标比较不同方案，为移动通信、网络和物联网通信技术的学习打下基础。

## 13. 电子技术基础

课程面向电子信息与物联网系统的入门需求，综合介绍常用电子元器件、基本电路和工程应用。内容一般覆盖电路基本分析、二极管和三极管等器件、放大与开关电路、逻辑电路、稳压电源、信号测量及常用仪器使用。学生需要学习识读电路图、正确连接实验电路并解释测试结果。课程帮助学生把电学理论转化为搭建、测试和调试简单电子系统的实际能力。

## 14. 数据库原理

课程研究结构化数据的组织、管理和使用方法。主要内容包括数据库系统架构、实体—联系模型、关系模型、关系代数、SQL、规范化、索引、事务、并发控制、恢复和权限管理。学生会完成表结构设计、数据查询和更新等实践，理解如何在数据一致性、查询效率和安全性之间进行权衡。课程培养把实际业务需求抽象为数据模型的能力，是信息系统和 Web 应用开发的重要基础。

## 15. 操作系统

课程解释计算机如何管理硬件资源并向程序提供统一服务。内容包括进程与线程、处理器调度、同步互斥与死锁、内存管理、虚拟内存、文件系统、设备和输入输出，以及系统安全等。学生通过分析典型机制或实验，理解并发程序为何会出错、资源如何分配以及程序如何装入和运行。课程有助于建立系统级思维，是云计算、嵌入式系统和高性能软件开发的基础。

## 16. 计算机组成原理

课程从硬件层面说明计算机如何执行程序。主要学习数据表示与运算、指令系统、CPU 数据通路与控制器、流水线、存储层次、输入输出和总线等内容。学生将高级语言程序、汇编指令和硬件执行过程联系起来，理解性能、成本与可靠性的权衡，并能分析缓存和流水线冒险等基本问题。课程连接数字电路与操作系统，是理解计算机系统结构的关键桥梁。

## 17. 计算机网络

课程讲授计算机和终端之间进行可靠通信的分层原理。通常以 TCP/IP 体系为主线，介绍物理层与数据链路层、以太网和交换、IP 编址和路由、传输层 TCP/UDP、DNS、HTTP 等应用层协议，以及网络安全基础。学生会通过抓包、配置或编程实验理解数据包从主机到网络再到应用的传递过程。课程为互联网应用、分布式系统、网络运维和物联网连接技术提供基础。

## 18. 计算机类研讨课

课程通常采用专题讲座、文献阅读、报告交流和小组讨论的形式，帮助学生认识计算机学科的前沿方向与真实工程问题。主题可能涉及人工智能、软件工程、系统与网络、数据安全、产业实践和学术规范。学生需要检索资料、提炼观点，并以口头或书面形式表达，在讨论中学习提出问题和开展协作。课程侧重拓宽视野、训练信息获取与沟通能力，为专业学习和科研实践建立起点。
